macOS 快速安装

deepseekdeskskin 0.13.0

已安装 DeepSeek Harness，即可将三套皮肤直接带入客户端。不需要另外安装 Node.js、Homebrew 或 Git。

三步完成

  1. 装好 DeepSeek Harness，至少打开过一次以完成初始化。等待任务结束，再按 ⌘Q 完全退出客户端；只关闭窗口不够。安装不要求先登录。
  2. 打开 macOS“终端”，复制并运行下面的命令。
  3. 看到安装成功后，重新打开 DeepSeek Harness，无需退出账号；从左侧“切换皮肤”选择澄蓝、经典女仆或 Q版。
curl -fsSL https://raw.githubusercontent.com/xingxingluolei/deepseekdeskskin/main/scripts/install-macos.sh | /bin/bash

安装器下载约 236 MiB 的发行包，校验 SHA-256 后调用客户端自带的官方 CLI。自动查找 /Applications/DeepSeek Harness.app 和 ~/Applications/DeepSeek Harness.app，不修改客户端应用包，也不会自动关闭或强行终止客户端进程。安装后可关闭工作室。

更新时，等待任务结束并按 ⌘Q 完全退出客户端，再运行同一条命令即可，无需先卸载。已有的插件停用状态会保留；此前停用过插件时，更新后仍需从 Harness 的插件管理中启用。

希望先阅读脚本，可查看 macOS 安装说明。

只检查、自定义客户端位置、本地发行包或卸载

先下载脚本并阅读：

curl -fsSL https://raw.githubusercontent.com/xingxingluolei/deepseekdeskskin/main/scripts/install-macos.sh -o install-macos.sh
less install-macos.sh

按需要选择命令：

# 只检查系统与客户端位置
/bin/bash install-macos.sh --check

# 客户端位于其他目录
/bin/bash install-macos.sh --app "/path/to/DeepSeek Harness.app"

# 使用下载好的 v0.13.0 发行包
/bin/bash install-macos.sh --package "$HOME/Downloads/deepseekdeskskin-harness-0.13.0.tgz"

# 卸载皮肤
/bin/bash install-macos.sh --uninstall

--package 只接受与内置校验值一致的 v0.13.0 发行包。自己导出的定制包使用下方手动安装方式。自定义客户端位置时，--app 可与检查、包路径或卸载选项组合。请以当前用户运行，不要加 sudo。卸载前也需按 ⌘Q 完全退出客户端，随后重新打开客户端生效。

手动安装发行包或工作室导出的定制包

从 GitHub 发行页下载 deepseekdeskskin-harness-0.13.0.tgz；也可在工作室中选好设置，展开“连接 DeepSeek Harness”，点击“导出 Harness 插件”。

确保客户端至少打开过一次，并在任务结束后按 ⌘Q 完全退出，再使用官方 CLI 安装。macOS 默认位置示例：

"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" \
  plugin --profile desktop add \
  "$HOME/Downloads/deepseekdeskskin-harness-0.13.0.tgz" --ignore-scripts

按实际位置替换客户端与包路径。add 可直接更新，无需先移除；已有插件停用状态会保留。安装后重新打开客户端，无需退出账号。

手动卸载前，也需按 ⌘Q 完全退出客户端：

"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" \
  plugin --profile desktop remove deepseekdeskskin-harness

皮肤与模式

左侧皮肤卡提供“切换皮肤”和“皮肤详情”。可选择澄蓝、经典女仆、经典女仆 · Q版，调整静态／动态、云间白／深海蓝、靠左／靠右，以及启用／关闭。侧栏折叠后点击头像进入设置。关闭皮肤后，左侧入口仍可重新启用。

每套角色有 21 张独立身体状态图。思考、翻书查阅、执笔写入、搜索、执行命令、分派任务、整理书架和错误等有不同动作。首次发送新对话时，十二张肩上关键帧用约 3.9 秒完成转头与微笑，随后恢复任务动作；后续追问不重复开场。报错、确认与停止等事件会立即中断开场。

人物在交互开始时保持清晰，持续工作后逐渐淡化；小窗口也保留人物。正文处使用柔和渐变，装饰不接收鼠标事件。静态模式仍根据任务换图，但不播放转场；系统“减少动态效果”也会关闭开场动画。

独立工作室与兼容范围

工作室用于开发、预览、导入素材与导出定制插件，独立运行需要 Node.js 20+。这与客户端快速安装分开，使用上面的安装器不需要安装 Node.js。

客户端安装目前仅适配 macOS，Windows/Linux 尚未验证。Harness 接口以 0.2.0-rc.2 为基线，其他版本需要重新验证。状态来自客户端公开数据；部分远程子任务及后台命令的退出信息未完整暴露，不会通过回答正文猜测状态。

人物为本项目 AI 生成的二创概念，非 DeepSeek 官方人物或素材。动画是独立 PNG 姿态与代码转场，不是 Live2D、骨骼动画或连续视频。19 段非人声音效目前仅提供试听与下载，尚未接入客户端自动播放。
