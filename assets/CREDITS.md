# 素材来源

本文件记录 deepseekdeskskin 0.13.0 当前采用的角色图片与音效来源。实际发布文件及其校验值以仓库内的 `docs/asset-manifest.json` 为准。

## 角色图片

澄蓝（`serene`）、经典女仆（`maid`）和经典女仆 · Q版（`maid_chibi`）均为本项目使用 OpenAI 内置 `image_gen.imagegen` 生成或编辑的二创概念。角色并非 DeepSeek 官方人物或素材；项目名称不表示合作、隶属或代言关系。

正式文件使用生成工具输出的独立副本，PNG 保留原始字节。全身动作和肩上开场图采用真实 RGBA 透明背景，分辨率为 1024 × 1536；头像和设定图的具体规格见素材清单。运行时不读取生成工具缓存或其他项目目录。

| 文件 | 用途与来源 |
| --- | --- |
| `assets/actions/*-v1.png` | 原始身体动作中继续采用的部分，包括回应、连接、暂停等姿态。 |
| `assets/actions/*-v2.png` | 整理书架、执笔书写、翻书查阅、放大镜搜索、递出任务卡。三套各五张。 |
| `assets/actions/*-v3.png` | 思考、通用工具、重试、排队、错误、断线、停止、完成。三套各八张。 |
| `assets/portraits/*-intro-*.png` | 每套十二张肩上开场关键帧，组合采用 v2、v3、v4 中的已接受素材。 |
| `assets/*-avatar-v1.png` | 三套角色的独立头像。 |
| `assets/serene-character-sheet-v1.png` | 澄蓝的正背面、表情与服饰设定。 |

每套皮肤包含 21 张独立身体状态图和十二张独立开场图。当前文件映射由 `src/skin.mjs` 定义。身体与道具用于表达任务，主要交流状态正面看向观众；开场单独保留先看左侧、再转头回应的过程。

逐张提示词、参考图标识、SHA-256 和构图记录保存在仓库 `docs/` 下，文件前缀 `serene`、`maid`、`chibi` 分别对应三套角色：

- `*-action-generation-v1.json`：原始全身动作与早期开场来源。
- `*-tool-actions-v2.json`：五类工具动作。
- `*-distinct-actions-v3.json`：八类强化动作与正面表情。
- `*-portrait-generation-v2.json`：高清肩上特写来源。
- `*-intro-cinema-v3.json`：开场转头与眨眼的中间关键帧。
- `*-softfront-v4.json`：自然对视、微笑与连续朝向修订。

公开记录移除了个人机器路径。部分记录用于说明历史参考链，所引用的旧版图片不一定随当前版本打包。它们不表示运行时依赖。

人物转场、呼吸、镜头位移、鲸尾图标和界面波纹由项目代码实现。图片之间存在生成差异；动态图像不是骨骼动画、Live2D 或连续逐帧视频。头像聚焦只改变显示位置，不修改源图像素。

本次公开版本不包含用户已有的第三方旧 GIF，也不包含 LLMPET 的图片、动画或其他运行资源。

## 非人声音效

`assets/audio/ui-v1/` 包含 19 段短音效、核心串听与完整串听，由本项目 `scripts/generate-sfx-v1.py` 原创程序合成。使用衰减振荡器、滤波噪声与轻微声场模拟水晶、纸张和木质质感；没有人声、外部采样或实物录音。

音频规格为 48 kHz、16-bit、双声道 WAV。生成需要 Python、NumPy、SciPy；播放只需标准 WAV 解码。时长、电平、SHA-256 和建议对应状态见 `assets/audio/ui-v1/manifest.json`，文件说明见同目录 `README.md`。

此版仅提供素材与试听，尚未接入客户端自动播放。
