# 镜头式开场 · 0.13.0

三套皮肤各使用十二张独立肩上关键帧，运行目录映射见 `src/skin.mjs`。保持最初向左看、收到新任务才转向观众微笑，以及开场期间脸部清晰的规则。

| 帧 | 动作 | 停留 | 图像过渡 |
|---|---|---:|---:|
| away | 左看待机，短暂停留 | 280ms | 160ms |
| attention-eyes | 先用目光注意到你 | 240ms | 210ms |
| noticing | 目光回应 | 280ms | 230ms |
| turn-early | 开始转头 | 260ms | 220ms |
| turning | 转向观众 | 320ms | 270ms |
| turn-late | 接近正视 | 300ms | 250ms |
| front-neutral | 双眼水平，正视镜头 | 320ms | 250ms |
| front-blink | 轻轻合眼 | 180ms | 100ms |
| front-open | 睁眼回应 | 240ms | 140ms |
| soft-smile | 笑意展开 | 320ms | 260ms |
| front-smile | 温柔微笑 | 540ms | 320ms |
| smile-settle | 笑容稍放松，停留 | 620ms | 320ms |

总长 3900ms。镜头在整段开场中只运行一次：逐渐推进至最多 1.022 倍、向上移动最多 4px，在末段轻轻回到原位；随后沿用原生布局 620ms 的位置衔接。镜头叠加于既有定位与左右镜像，不修改人物裁切。它与换图、遮罩独立，神态更换不会重启镜头。

开场后的 2400ms 清晰停留、3200ms 阅读淡化和 800ms 恢复沿用 0.9.1。静态、关闭动作和系统减少动态效果不播放镜头与开场。错误及交互请求仍立即释放正文，取消开场和镜头；不延迟实际模型任务。

这是 12 张独立绘制关键帧、双缓冲渐变与连续镜头运动的组合，不是真实视频补帧、骨骼动画或 Live2D。脸部角度与眨眼有新增动作，细小发丝、衣纹仍可能有重绘差异。

素材生成与原始来源分别记录在 `serene-intro-cinema-v3.json`、`maid-intro-cinema-v3.json`、`chibi-intro-cinema-v3.json`。图片原始字节保存在本项目 assets/portraits；没有运行时外部资源依赖。

## 取景范围

上述 12 帧开场限定在新会话首次发送时；空白首页继续显示左看的肩上首帧。进入任务后切换回 `assets/actions/` 的完整身体动作，已有会话的后续任务与待机不再放大为肩上特写。每个渲染缓冲独立保存取景方式，避免新动作解码期间改变旧画面裁切；状态图采用 420ms 渐变，阅读淡化时序保持不变。
