# 任务神态 · 0.13.0

三套角色各对应 21 种工作状态。身体与道具可朝左表达任务，脸部主要正面朝镜头，不要求脸必须朝左。新会话安静等待，只在第一次发送时用 12 帧、约 3.9 秒的肩上特写完成注意、转头、对视和微笑，再交回当前任务的完整身体动作。已有对话继续使用身体动作，不重复开场。静态模式、关闭动作和减少动态效果跳过演出；错误、确认、停止等介入态立即接管。

本版为思考、工作、重试、排队、出错、断线、停止与完成换用独立动作，每套 21 个状态分别对应 21 张源图。工具细分与书架整理继续沿用各自动作。正常结束先显示完成鞠躬，六秒后真实状态回到 `idle`，显示层保留回应收尾，不伪造任务仍在回答。

## 公开信号与范围

适配基线为 DeepSeek Harness 0.2.0-rc.2。完整信号、有效范围和来源记录在 [DSH 公开状态库存](dsh-state-inventory.json)。仅通过公开客户端服务与插槽读取结构化元数据；不读取用户私有会话日志，不对任务正文、推理、工具参数、错误描述或子任务总结做关键词分类。

| 状态 | 可靠来源 | 对应画面 |
| --- | --- | --- |
| 就绪 | 无运行、确认、排队或需保留的终止态 | 空会话安静等待；有真实已完成回答时保持回应姿态 |
| 思考中 | 会话运行或等待首轮，没有更明确阶段 | 站立托下巴思考，不拿书 |
| 工作中 | 当前开放轮次中未识别工具的活动叶调用；本会话后台任务 running/stopping | 俯身操作低位工具箱与机械部件 |
| 查阅中 | 当前活动叶工具的公开 `name` 为 read/read_image/web_fetch | 翻看打开的书，手指沿页查阅 |

| 连接中 | 原生 connection connecting，包括重连/backoff | 寻找连接 |
| 连接中断 | 原生 connection disconnected；当前轮明确 signed-out hook | 双手拉开两只大插头 |
| 已停止 | 当前轮 aborted/interrupted；已知任务取消的终止状态 | 胸前交叉前臂，摆出大 X |
| 已暂停 | 当前真实目标 phase=paused | 放松清醒，等待恢复 |
| 需要介入 | 当前真实目标 blocked 或当前轮明确 blocked | 张掌请求帮助 |

工具分类读取公开 Chat 投影 `legacy.runningCalls` 和嵌套 `subCalls` 上的 **wire 工具名 `name`**，严格匹配列出的名称。`phase:start`、当前 `turn`、无 `kind` 的真实运行叶调用才参与分类；`preparing`、历史结果与外层包装不会冒充子工具。未知扩展工具，例如 `load_workspace_dependencies` 或任意名称中恰好含有 write/read 的第三方工具，保留通用工作姿态。不会分析参数以猜测用途。

等待确认、连接、目标暂停/阻塞与当前提交/加载错误优先于普通忙态。整轮失败优先于仍在运行的后台工作；局部失败先反应，再按最新阶段恢复。正常忙态中，整理 → 计划重试 → 并行 → 单工具动作/通用工作 → 回应 → 思考。单个活动叶显示其动作；多个活动叶或真实子任务运行显示并行。排队只在没有更明确运行阶段时显示；连接的 undefined 表示来源未就绪，不表示断线。

动态模式中，实际观察到的五类细分工具动作先等待图片解码与完整淡入，再保留 **900ms** 的清楚停留。排队、加载或不可见等待最多 **三秒**；失败或超时释放动作，恢复最新真实状态。渲染回执通过轮次隔离后的 epoch、状态与角色校验，同一回执不会重复延长，旧回执不能恢复已取消的动作。

标签和真实进程即时前进；只保留最新工具，报错、确认、停止、暂停、阻塞、断线、新会话与新轮次立即取消保留。换皮肤、关闭、静态、关闭动作和减少动态效果也取消。不会给同一批到达且从未观察到运行的 call/result 补播动作；首次 3.9 秒开场仍优先，开场和未挂载的显示区域不积累旧动作，重新显露时只展示当前真实状态。

## 失败、历史和计时

局部工具、PTC 子调用、助手请求、后台任务或整理失败，使用至少 **四秒**的可见错误反应；模型继续执行不会立刻冲掉错误图，计时结束恢复最新真实状态。等待、断线、暂停等更高优先级状态暂缓该反应，恢复后再显示。整轮失败持续至新任务；当前历史尾轮失败重开也可显示。取消/中断不显示成功，初次历史读取不会重放旧局部失败。

0.12.0 修复两个遗漏入口：

- **迟到的权威错误**：事件源与 Chat 投影独立发布。已经观察过的当前轮刚显示 completed，随后到达的 `tool/result` 或 assistant finish 错误仍得到四秒反应，不被“完成”吞掉。瞬态前台 Bash receipt 也使用同一轮次准入边界。旧历史、已提交下一任务、另一会话不获得此资格；成功与取消不会打断完成状态。反应后重新判断真实进程，若确实完成再给予完整的六秒完成状态。
- **嵌套 PTC fallback**：原始事件服务缺席时，工具结果可能仍嵌套在活动根工具的 `runningCalls[].subCalls`，尚未进入 `legacy.nodes`。现在递归检查两种公开投影，仅关联实际观察的当前 callId，过滤取消并按 callId/seq 去重；同一失败随后进入根结果或原始事件不会重复反应。遍历带循环检测与深度上限。

动态模式进入 `error`，在新图解码与布局交接完成后播放 **1.3 秒**的克制轻退：先向右 4px、缩至 0.986，再缓和回到原位。每次进入错误或错误中切换角色播放一次；同一错误的普通更新不重复。静态、关闭动作、减少动态效果时只换错误图，不播放位移；离开错误与卸载会取消动画，结束不留下变换样式。动画发生在外层人物容器，不改图片像素或每张图的朝向。

实际观察的主轮收到权威 `turn/end`、`reason.kind=completed` 后，真实 `complete` 状态保留 **六秒**，再成为 `idle`。当前活跃工作、新任务、连接变化或其他优先状态可推迟或取消完成状态。前台 Bash 的 roster 消失不能推翻已确认的主轮完成，但消失本身也不证明成功。没有权威结束时，空列表、掉线和未知状态不能提供完成证明。

## 回答结束时的画面与真实状态

`complete` 使用独立的提裙浅鞠躬源图。已有真实正常完成的 transcript，在不运行、不等待首轮、未移除、没有待提交内容及 inbox 工作时，`idle` 也只在**显示层**采用回应姿态。这样回答结束后继续保持回应收尾；空会话仍使用待机动作。历史正常完成不会重放完成计时或开场。停止、错误、暂停、阻塞等仍保持各自真实画面。

## 订阅与边界

以主视图 `retainedBy.mainView` 选择驱动会话，嵌入子任务面板不能抢主场景。切换会话重置观察范围，换皮肤不重建 tracker；关闭皮肤仍跟踪，卸载清理监听、任务 watcher、计时器和图片 URL。服务暂未就绪时等待下一次公开发布重试，没有日志轮询。

正式 host companion 从前台 Bash 的 `canonical.value` 与原生本地 subagent 生命周期读取元数据，通过官方 Typert Remote 瞬态 stream 传到客户端。只带白名单退出码/终止原因，不带工具输入输出或子任务总结，不修改原结果、不追加持久会话事件，也不进入模型正文。每次 stream 打开建立空基线，只处理其后的实时结果；断开期间未知结果不从日志补猜。

后台任务只观察本会话 owner 对应 roster/status，不订阅 output。公开 roster 的 completed 只能证明工作结束，不能推出 exitCode=0。后台/已提升 Bash 若没有 typed exitCode/signal，不通过 detail 文本推断。正式 companion 通过公开 `agents.isOwnedBy` 证明本地子任务的精确 runtime 父归属；无法证明的远程/第三方子任务不从 summary 推断结果。完整限制见状态库存的 `unsupported`。

状态语义只读参考 LLMPET 的显式事件设计，没有复制代码/素材，没有接入其进程或配置；运行资源由 deepseekdeskskin 独立提供。

## 查看画面与验证范围

客户端左侧 **皮肤详情 → 神态预览**、独立 `/web/design.html` 与 `/web/current-state-gallery.html` 提供三套角色 21 种状态对照。图鉴为 63 张状态卡，对应 63 张独立 PNG：通用工作操作工具箱，命令执行操作电脑；完成鞠躬与回应解释分别展示。手动画册仅预览，不伪造运行任务状态。

初始和新会话第一次发送为肩上特写，后续任务保留身体动作；窗口缩小时人物继续保留并按阅读阶段淡化。新开场被错误、确认、停止、暂停、断线、介入等及时取消。12 张独立关键帧配合浏览器过渡，存在少量发丝衣纹差异，不是骨骼动画或 Live2D。

本文记录代码中的设计与接入边界，不代表所有原生客户端状态都已现场验收；实际覆盖范围以对应版本验证记录为准。
